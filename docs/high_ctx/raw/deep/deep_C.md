### 2603.27045 — Rushil Raghavan, Improved Bounds for 3-Progressions (본문 24쪽, v3 2026-05-15, 읽은 범위: 전체, 부록 A와 참고문헌 11편 포함)

**주정리.**
- 정리 1.4 (2쪽, {1..N}): A ⊆ {1,…,N}에 자명하지 않은 3항 등차수열이 없으면 |A| ≤ exp(−log(N)^{1/6−o(1)})·N. 더 정확히는 |A| ≤ exp(−Ω(log(N)^{1/6}·log log(N)^{−1/6}))·N. 쉬운 말: 3항 등차수열을 피하는 집합의 크기 상한에서 "지수"를 Bloom–Sisask의 1/9에서 1/6로 올렸다는 주장입니다.
- 정리 1.5 (2쪽, F_q^n, q ≥ 3 소수, N = q^n): 3항 등차수열이 없으면 |A| ≤ exp(−Ω(log(N)^{1/5}))·N. 쉬운 말: 정수 대신 "각 자리가 소수 q 위의 수인 벡터" 세계(유한체 모형)에서 쓴 연습판입니다. 저자가 직접 "새로운 결과가 아니다"라고 적었습니다(Ellenberg–Gijswijt 다항식 방법이 더 좋음, 2쪽).
- 인용된 배경(증명 없음): 정리 1.2 Kelley–Meka(지수 1/12), 정리 1.3 Bloom–Sisask(지수 1/9), 아래쪽은 Behrend의 exp(−c·log(N)^{1/2})·N이고 Elsholtz–Hunter–Proske–Sauermann이 상수를 개선했다고만 적힘(1쪽).
- 명제 3.1 (6쪽, F_q^n): (1) |⟨µ_A∗µ_A, µ_{−2·A}⟩ − 1| ≤ 1/2 (진행이 충분히 많다) 이거나, (2) 공간 V(차원 구멍 수 "여차원" O(L(α)^4))가 있어 ‖µ_A∗µ_V‖_∞ ≥ 1 + 2^{−5} (밀도가 일정 비율 늘어나는 조각이 있다). 여기서 L(α) = log(2/α).
- 명제 4.2 (10쪽, Z/NZ, N 홀수): 정칙 Bohr 집합 B 위에서 (1) 진행이 ≥ (1/4)α³N²µ(B₁)µ(B₂)개 있거나, (2) σ ∈ [1+2^{−12}, α^{−1}], 계수(rank) ≤ d + O(L(α)^4), 반지름 ≥ Ω((c/2dL(α))^{O(log σ)}·ρ)인 Bohr 집합 B′ 위에서 상대 밀도가 σ배 이상 늘어난다. 쉬운 말: Bohr 집합은 "정수를 원 위의 각도로 보아 여러 각도가 동시에 거의 0인 수들의 모임"으로, 정수 세계에서 부분공간 역할을 하는 도형입니다.
- {1..N}에서 Z/(2N+1)Z로 넣어 새 진행 없이 옮긴다(10쪽). 결말은 N ≤ exp(O(L(α)^6 log L(α)))(정수, 11쪽)와 N ≤ exp(O(L(α)^5))(유한체, 7쪽)입니다.
- 핵심 보조정리의 진술: 보조정리 3.3(유한체 반복 체질, 6–7쪽), 보조정리 4.5(정수 반복 체질, 13쪽), 보조정리 4.6(가중 체질, 13–14쪽), 보조정리 4.8(15–17쪽), 부록 보조정리 A.8(23쪽).

**증명의 뼈대.**
- §2.2 (4–5쪽)에 5단계 설계도가 있습니다. (1) Hölder 끌어올림과 불균형 풀기: ‖µ_A∘µ_A‖_p가 크다(p = O(L)). (2) 체질(sifting): 충분히 큰 값의 집합 S 위에서 ⟨µ_{A1}∘µ_{A2}, 1_S⟩가 큰 부분집합 A₁, A₂를 찾는다. (3) Croot–Sisask 거의 주기성. (4) 부트스트랩(Chang 보조정리, Bohr 집합 V를 얻음). (5) 밀도 증가.
- §3 (6–9쪽) 유한체: 위 5단계를 그대로 실행. 새 점은 보조정리 3.3입니다. 체질을 한 번만 하지 않고, ⟨µ_A∘µ_A, µ_{A_i}∘µ_{A_i}⟩ ≤ 2σ가 될 때까지 "더 성긴 집합쌍으로 다시 체질"을 최대 O(L(α))번 반복합니다(7쪽). 이것으로 Bloom–Sisask가 "개선 여지"라고 짚은 식 ⟨µ_A∘µ_A, µ_{A1}∘µ_{A2}⟩가 코시–슈바르츠 상한에 가깝게 되는 입력을 얻고(5쪽 식 (1) 부근), 부트스트랩 손실을 줄입니다. 9쪽 Remark: 이 논증은 밀도가 단순 (1+Ω(1))배가 아니라 σα배(σ ≥ 1+2^{−5})로 늘어나는 것을 줍니다. 유한체에서는 이득이 없지만 정수에서 Bohr 집합 반지름을 아끼는 데 쓰입니다.
- §4 (9–21쪽) 정수: 같은 틀을 Bohr 집합 위에서 합니다. 새 점이 셋입니다. (a) 반지름을 매우 조심스럽게 추적: 각 단계의 반지름 축소가 (c/2dL)^{O(log σ)}(σ가 클수록 많이 줄지만 총합 Σlog σ_j ≤ log(1/α) = O(L)이라 누적 반지름은 exp(−O(L log L)), 10–11쪽). (b) 보조정리 4.6–4.7의 가중 체질로 체질 후 집합 밀도를 더 세밀히 통제(13–15쪽). (c) 보조정리 4.8: 거의 주기성 단계에서는 A_{2j−1}과 A_{2j}가 서로 다른 폭의 Bohr 집합에 놓여야 하므로 µ_{A1}∘µ_{A1}에 대해 체질하는 것이 불가능하다고 설명하고(5쪽), 확률적 논증으로 우회합니다(15–17쪽). 보조정리 A.8(23쪽, Schoen [9, 보조정리 12]에서 가져옴)은 α에 의존하지 않고 δ ≈ c/d 크기의 Bohr 집합 축소까지 쓸 수 있게 해 줍니다.
- 부록 A (21–23쪽): Bohr 집합 기본 성질. 보조정리 A.4(|B_ρ| ≥ (ρ/4)^d|B|)가 마지막 계산에 들어가 μ(B′)μ(B″) = exp(−O(L^6 log L))를 줍니다.
- 제가 식을 따라가 확인한 것: 반지름 ρ_J ≥ exp(−O(L log L)), 계수 d ≤ O(L^5)이므로 μ ≥ exp(−O(L^6 log L)). 이 log L이 정리 1.4의 log log N 꼴이 생기는 곳입니다(제 해석).

**방법이 막히는 곳.**
1. 5쪽 마지막 문단: Bohr 집합 밀도 증가 논증은 매 단계 Bohr 집합 반지름이 α^{O(1)}배로 줄고, 단계가 O(L(α))번이라 유한체와 Z/NZ 사이에서 "로그 두 개 손실"이 난다고 설명합니다. 이 논문은 이를 지수 역수 기준 5(유한체)와 6(정수)로, 즉 "1 + o(1)" 차이로 줄였습니다. 이 손실을 더 줄이는 길은 §2.2 끝에서 "unclear"로 남아 있습니다.
2. 5쪽: Bohr 집합 밀도 증가로 exp(−log(N)^{1/2−o(1)})(Behrend와 거의 일치)에 이를 수 있는지 "분명하지 않다". 가능하다면 유한체와 정수 사이에 "로그 하나"의 손실이 있어야 한다고 적었습니다. (제 해석: 정수에서 1/2에 이르려면 유한체에서는 지수 1에 해당, 즉 다항식 절약과 같은 급이 필요해 보이는데, 본문은 이를 풀어쓰지 않았습니다.)
3. 2쪽: 유한체에서는 다항식 방법(Ellenberg–Gijswijt)이 이 논문의 1/5보다 낫고, "그 방법의 정수판은 알려져 있지 않다"(문장: 이 방법은 {1..N}에 대응물이 없음). 정수 쪽은 체질 + Bohr 집합 증가 이외의 길이 없다는 뜻입니다.
4. 5쪽 식 (1) 주변: 이상적 입력 ⟨µ_A∘µ_A, µ_{A1}∘µ_{A1}⟩^{1/2}⟨…⟩^{1/2} ≤ C⟨µ_A∘µ_A, µ_{A1}∘µ_{A2}⟩가 곧바로는 성립하지 않아 반복 체질(O(L)번)의 비용을 치릅니다. 이 반복 횟수가 성긴 집합의 밀도를 α^{O(L(α))}로 만듭니다(7, 18쪽). 방법 내부의 병목입니다.
5. 15쪽 보조정리 4.8과 17쪽: 서로 다른 Bohr 집합에 두 집합을 놓으면 상대 밀도가 min(α^{O(1)}γ, α^{L(α)/log 2+O(1)}) 수준으로 떨어집니다. α^{L(α)}가 최악 손실입니다.
6. 10쪽: 정칙(regular) Bohr 집합 조건과 계수 d가 쌓이는 문제로, 단계마다 계수가 O(L^4) 늘어(d ≤ O(L^5)) 최종 Bohr 집합 크기가 exp(−O(L^6 log L))가 됩니다. 이 L^6이 지수 1/6의 직접 원인입니다.

### 2509.22962 — Sarah Peluse, Finding arithmetic progressions in dense sets of integers (본문 26쪽, 읽은 범위: 전체)

**주정리.** 이 글은 서베이라 새 정리는 없고, 아래 정리를 정확히 진술합니다.
- 정리 1.1 (Szemerédi 1975, 2쪽): 고정한 k ≥ 3에 대해 A ⊂ {1..N}에 자명하지 않은 k항 등차수열이 없으면 |A|/N = o(1). 쉬운 말: 충분히 큰 범위에서 일정 비율을 고르면 k항 등차수열이 생긴다.
- 식 (1.2) (Roth 1953, 3쪽): k=3에서 |A|/N = O(1/log log N).
- 정리 1.2 (Gowers 1998 k=4, 2001 k≥4, 3쪽): |A|/N = O(1/(log log N)^{2^{−2^{k+9}}}). (추출 텍스트가 "2−2k+9"로 깨져 있어 Gowers의 알려진 꼴로 읽었습니다. PDF 대조는 못 했습니다.)
- 정리 1.3 (Green–Tao 2017, 4쪽): k=4에서 |A|/N = O(1/(log N)^c).
- 정리 1.4 (Leng–Sah–Sawhney 2024, 4쪽): k ≥ 5에서 |A|/N = O(1/exp((log log N)^{c_k})), c_k ∈ (0,1)은 k에만 의존. c_k의 값은 적혀 있지 않습니다.
- 식 (2.5) (Kelley–Meka 2023, 8쪽): k=3에서 |A|/N = O(1/exp(C(log N)^{1/12})), Bloom–Sisask가 1/9로 개선(8쪽).
- 정리 3.2 (Gowers의 국소 역정리, 12쪽), 정리 5.1 (Green–Tao–Ziegler 2012 전역 역정리, 18쪽), 정리 5.2 (U³ 준다항식, Green–Tao + Sanders, 19쪽), 정리 5.3 (Manners 2018, U^{s+1}, s ≥ 4, 이중 지수 경계, 19쪽), 정리 5.4 (Leng–Sah–Sawhney 2024, 준다항식 경계: 차원 d = O(log^{O_s(1)} δ^{−1}), 복잡도 M, K = exp(log^{O_s(1)} δ^{−1}), 상관 exp(−log^{O_s(1)} δ^{−1}), 20쪽). 쉬운 말: "어떤 함수가 어떤 '균일성 척도'(고워스 노름)에서 크면 반드시 특별한 꼴의 함수(니일수열)와 상관을 가진다"는 정리들이고, 5.4는 이를 매우 효율적인 상수로 만든 것입니다.
- 정리 3.2의 진술에는 오타로 보이는 곳이 있습니다(α^{c_s}라고 쓰였는데 α가 정의되지 않음, δ일 듯). 정리 5.4는 s ≥ 4로 쓰는데 본문 문장은 "모든 s ≥ 5"라고 달리 적었습니다(U^s 대 U^{s+1} 표기 혼용, 제 해석).

**증명의 뼈대.**
- §2 (4–8쪽): Z/MZ(M 홀수)에서 푸리에 해석으로 3항 등차수열의 개수 공식 Λ₃(f,g,h) = Σ f̂(ξ)ĝ(−2ξ)ĥ(ξ) (식 2.2)를 얻고, 진행이 없으면 1_A의 푸리에 계수가 0이 아닌 주파수에서 커야 한다는 식 (2.3)을 얻는다. {1..N}에서 Z/MZ(M ∈ (2N,4N))로 옮기는 것을 설명.
- §3 (8–14쪽): k ≥ 4부터는 푸리에만으로는 안 되는 이유. 다항식 항등식 x² − 3(x+y)² + 3(x+2y)² − (x+3y)² = 0 (식 3.1)으로 푸리에 계수가 모두 작지만 4항 진행이 최대로 많은 함수를 만든다(8–9쪽). "이차 Bohr 집합" 반례도 있음. 그래서 고워스 U^s 노름(식 3.4)이 나오고, 진행 개수의 오차는 (k−2)‖f_A‖_{U^{k−1}} 이하(식 3.6). U² 노름의 역정리는 푸리에 변환 그 자체(보조정리 3.1). U^s(s ≥ 3)부터는 국소 역정리(정리 3.2)만 있고 전역 판은 거짓(식 3.9의 반례, 12쪽).
- §4 (14–18쪽): 니일수열(정의: 필트레이션이 있는 멱영 리 군 + 다항 수열 + 연속 함수). 아무 함수나 니일수열이 되는 문제를 막으려 차원·복잡도·립시츠 상수를 제한해야 함을 3가지 반례로 설명(17쪽).
- §5 (18–22쪽): 전역 역정리의 역사(3.2→5.1→5.2→5.3→5.4)와 장난감 증명(‖f‖_{U^s}=1이면 다항식, 20–21쪽 코사이클 논증). 실제 증명에서는 "통계적 코사이클 항등식" Ex ψ_h(x)ψ_{h+k}(x−ℓ)ψ_{h+ℓ}(x)ψ_{h+k+ℓ}(x−ℓ) = Ω(1)을 쓰며(22쪽), Leng–Sah–Sawhney의 핵심 새 아이디어는 새 균등분포(equidistribution) 정리로 이 정보를 한 번에 얻어 반복 횟수를 줄이는 것(22쪽). 구체적 보조정리 번호는 이 글에 없습니다.
- §6 (22–24쪽): 밀도 증가. 진행이 없는 A는 (1) 아주 작거나 (2) 긴 등차수열 P 위에서 밀도 α + α^{D_k}가 된다. 이를 반복해 Gowers 경계를 얻는다. Heath-Brown–Szemerédi의 아이디어(여러 주파수에서 동시에 거의 상수인 긴 등차수열로 분할, 디리클레 근사)가 Roth의 log log를 log 거듭제곱으로 바꿨고, Green–Tao(k=4)와 Leng–Sah–Sawhney(k ≥ 5)가 이 방법을 니일수열로 옮긴다(24쪽). Leng–Sah–Sawhney가 극복한 어려움은 "여러 니일수열이 동시에 거의 상수인 긴 등차수열 분할을 찾기"이다(24쪽).

**방법이 막히는 곳.**
1. 8–9쪽: k ≥ 4에서 푸리에 해석은 부족하다(식 3.1의 이차 위상 반례). 이것이 고차 푸리에 해석의 출발점.
2. 4쪽: Green–Tao의 k=4 논증은 더 긴 진행으로 "일반화되지 않는다". 그래서 k ≥ 5는 2024년까지 Gowers 경계가 유일했다.
3. 12쪽: Gowers의 국소 역정리는 "전역 판"으로 강화되지 않고(식 3.9), 소수의 짧은 구간 분포나 소수 위의 진행 같은 응용에는 불충분.
4. 12–13쪽: 국소 역정리의 역은 거짓(무작위 다항 위상 반례).
5. 17–18쪽: 니일수열의 정의를 느슨하게 하면 모든 함수가 니일수열이므로 차원, 복잡도, 립시츠 상수 상한이 필요(방법의 필요 조건).
6. 22쪽: 1) 상관이 작은 상태로는 코사이클 항등식을 정확히 얻을 수 없어 통계적 판으로 대체, 2) "ψ_h가 정확히 미분일 수는 없다"(too much to hope for).
7. 24쪽: 여러 니일수열을 동시에 거의 상수로 만드는 분할이 어려운 점. k=3에서 로그 거듭제곱을 얻는 Heath-Brown–Szemerédi 방식이 정확히 이 분할에 의존하며, 이것이 k ≥ 5 개선이 늦게 온 이유.

### 2504.07006 — Jaber, Liu, Lovett, Ostuni, Sawhney, Quasipolynomial bounds for the corners theorem (본문 75쪽 + 표지, v2 2025-07-14, 읽은 범위: 전체, 증명 상세 포함)

**주정리.**
- 정리 1.1 (3쪽): 유한 아벨 군 G, A ⊆ G×G가 코너 없음(즉 (x,y), (x+d,y), (x,y+d) ∈ A, d ≠ 0인 x,y,d가 없음)이면 |A| ≤ |G|²·exp(−c(log|G|)^{1/600}). 쉬운 말: 격자 모양의 점 G×G에서 "직각 삼각형 꼴(코너)"을 피하는 집합의 비율 상한이 로그의 거듭제곱 지수 1/600인 준다항식 꼴로 줄어든다.
- [N]×[N]에 대한 결론은 [N]을 Z/(4N)Z로 넣으면 얻어지고, Green의 기법([62, 보조정리 6.2])으로 d > 0만 허용해도 거의 같다(3쪽). 따라서 정수 [N]² 판은 이 논문에서 해결됨(지수 1/600).
- 정리 1.3 (3쪽, F₂ⁿ×F₂ⁿ, N = 2ⁿ): |A| ≤ N²·exp(−c(log N)^{1/178}).
- 따름정리 1.2 (3쪽): 충분히 작은 상수 c에 대해 G×G×G를 c·log log log|G| 색으로 칠하면 같은 색 3차원 코너(점 (x,y,z), (x+d,y,z), (x,y+d,z), (x,y,z+d))가 존재. 쉬운 말: 3차원에서 "색칠 판"의 결과로, 밀도 판이 아닙니다.
- 따름정리 1.4–1.6 (4쪽, Fox 개인교신 인용): 비가환 군 G에서 BMZ 코너, 단순 코너, 방정식 xy = z² (x,y,z가 모두 같지 않음)에 대해 상한 |G|²·exp(−c(log|G|)^{1/1200}) (마지막은 |A| ≤ |G|·exp(…)). 증명은 Pyber의 정리(가환 부분군 H, |H| ≥ 2^{Ω(√log|G|)})와 정리 1.1에서 나옴. 이전 최고는 Sanders의 |G|²(log log|G|)^{−1}, S_n에서는 Keevash–Lifshitz의 N·e^{−Ω((log log N)²)}(4쪽).
- 따름정리 1.7 (5쪽): 3인 Number-on-Forehead(NOF, "이마에 숫자를 붙인 통신 모델") 비결정적 프로토콜로 Exactly-N을 계산하는 데 Ω((log N)^{Ω(1)}) 비트가 필요. 따름정리 1.8 (5쪽): 4인 NOF에서는 Ω(log log log log N).
- 정리 7.9 (68쪽, 계수 판): |A| = α|G|²이면 코너의 비율이 ≥ 2^{−O(log(1/α)^{600})}. 정리 1.1의 정량적 본체이며 따름정리 1.2, 1.8의 입력.

**증명의 뼈대.**
- §2 (6–13쪽)가 전체 설계도입니다. Shkredov의 방법: A의 균형 함수 1_A − α가 큰 박스 노름을 가지면 직사각형 X×Y 위에서 밀도가 α^{O(1)}만큼 오르는 증가가 있고, X, Y를 푸리에 의사난수로 만들려 여차원 δ^{−O(1)}의 부분공간으로 간다. 로그 손실이 둘: 밀도 증가 단계 수(α^{−O(1)})와 의사난수화(6–7쪽, §2.1).
- 새 아이디어 ①: Hölder 조작으로 증가량을 (1+ε)배로 올려 단계 수를 O(log(1/α))로 줄임(§2.2, 7–9쪽). 박스 노름(grid norm) ‖·‖_{G(2,k)}, k ≈ log(1/α), 스펙트럼 양성(보조정리 4.2: ‖A−α‖_{G(2,k)} ≥ εα이고 열 평균이 아래로 안 처지면 ‖A‖_{G(2,p)} ≥ (1+ε²/36)α, 21쪽).
- 새 아이디어 ②: "(X,Y,D)-집합" S(X,Y,D) = {(x,y): x∈X, y∈Y, x+y∈D} 위에서 밀도 증가를 유지(§2.2, 8쪽). 옛 방식은 X×Y만 유지.
- 새 아이디어 ③: 상대 체질(정리 3.5, 17쪽, §2.3 9–11쪽). 함수가 S(X,Y,D) 같은 성긴 의사난수 집합 T 위에 놓여 있어도, 체질로 얻는 직사각형의 크기가 T의 밀도 τ에 의존하지 않게 함. Conlon–Fox–Zhao의 "densification"을 Cauchy–Schwarz 대신 Hölder로 해서 α 인자를 잃지 않음. 쓰이는 조건은 "조합적 spread"(정의 3.1)로, 컷 노름 의사난수성보다 약해 준다항식 경계에 충분.
- 새 아이디어 ④: 비대칭 증가(§2.4, 11–12쪽). D 쪽은 정보를 버리고(D의 지시함수를 추적하지 않고) k ≈ log(1/(αδ_D))로 잡아 D에는 의사난수 조건을 요구하지 않음. 결과적으로 D가 X, Y보다 훨씬 밀함(‖D‖ 쪽 밀도 하한 2^{−O(log³)} 대 X, Y의 2^{−O(log⁹)}).
