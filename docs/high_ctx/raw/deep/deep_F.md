## K5. 다항식 세메레디

### 2506.13010 — Altman, Sawhney, On polynomial progressions via transference (34쪽, 읽은 범위: 전체)

**주정리.**
- 정리 1.1 (쪽 2). P(y)는 정수계수 다항식이고 P(0)=0. a_1..a_t는 서로 다른 정수. 집합 A가 {1..N}의 부분집합이고 x, x+a_1P(y), ..., x+a_tP(y) (y가 0이 아니고 항들이 서로 다름) 모양을 하나도 포함하지 않으면 다음이 성립합니다. 상수 c는 P의 차수와 t에만 의존.
  - t=3이고 P'(0)≠0이면 |A| ≪ N exp(−c(log log N)^c).
  - P'(0)≠0이면(항 수 제한 없음) |A| ≪ N exp(−c(log log log N)^c).
  - P'(0)=0이면 |A| ≪ N (log log log N)^(−c).
  - 쉬운 말: "고정된 다항식 P의 값을 간격으로 하는 등차수열"이 들어 있어야만 하는 밀도의 기준을 처음으로 구체적인 수로 줌. 일반 k항 모양이면 가장 약한 세 번째 경우(세 번 로그)가 공통으로 성립(초록).
- 정의 1.3, 1.4. 다항식 묶음의 "핵 체계" κ(P)는 Σ Q_i(P_i)=0인 Q들의 모임. 모양 (x+P_1(y),...)가 "전달 가능"하다는 것은 P_i를 y, y^2, ..., y^d의 서로 독립인 변수 선형식 P_i*로 바꿔도 κ(P)의 모든 관계가 그대로 성립하는 것. "동차"는 κ(P)가 (c_1 z^i, ..., c_t z^i) 꼴로 생성되는 것. 전달 가능하면 동차임(쪽 3).
- 정리 1.6 (쪽 3). N이 소수, Z/NZ에서. 모양이 전달 가능이고 |f_i|≤1이면, 다항식 모양의 평균과 선형 모양(P_i*)의 평균의 차가 ≪ exp(−c(log log N)^c). 따라서 최대 밀도 r_P(Z/NZ) ≪ N exp(−c'(log log log N)^c'). 쉬운 말: 다항식 모양을 세는 것이 더 쉬운 선형 모양을 세는 것과 거의 같다는 "전달" 정리.
- 가정 주의: 정수에서는 "고정된 P의 배수 a_iP"만 다룸(일반 다항식 묶음 아님). Z/NZ에서는 N이 소수이고 모양이 전달 가능해야 함.
- 쪽 3 Remark 1.5의 예: (x, x+y, x+2y, x+y²)는 동차가 아님(2(x+y²)=2x+x²−2(x+y)²+(x+2y)² 라는 관계 때문). (x, x−y², x+y², x+y, x+y³, x+y+y³)는 동차이지만 전달 가능이 아님.

**증명의 뼈대.**
1. 절 1.1 (쪽 3–4), 전체 전략. 다항식 모양(예: x, x+y, x+2y, x+y³, x+2y³)을 y³ 자리에 독립 변수 z를 넣은 선형 모양과 비교하고, 선형 모양에는 이미 알려진 "초포화"(밀도가 크면 모양이 아주 많이 들어 있다는 결과)를 씀. 새 아이디어는 "차수 낮추기"를 피하고 비교를 닐수열(nilsequence) 문제로 옮긴 것(쪽 3 끝).
2. 비교의 틀은 "stashing"(Manners의 Cauchy–Schwarz 기법). 쌍대함수 D_j를 만들고 Cauchy–Schwarz를 써서 각 f_j를 닐수열 ψ_j로 하나씩 바꿈. 고워스 노름 통제(PET, Peluse)와 Leng–Sah–Sawhney의 준다항식 역정리(정리 2.13)를 씀 (쪽 4, 18–20).
3. 절 2 (정수, 쪽 5–20). 2.1 Hensel 보조정리 2.1, 2.2로 "W-속임수": w=(log N)^(1/2), W는 w 이하 소수들의 곱 꼴(식 2.1). P_W(y)=W^(−d')P(Wy)가 y^{d'}와 같은 분포를 갖게 함. 2.2 두 연산자 Λ_W와 Λ_Model(정의 2.5)을 비교. Λ_Model은 간격이 (±zW+1)y^{d'}이고 고대(아르키메데스) 가중치 ν(y)를 둠. 이유는 P(y)=y²−y⁴ 같은 경우 간격이 거의 항상 음수인데 비교 대상 간격은 양수라서 부호를 맞추려는 것(쪽 4–5, 8). 보조정리 2.6, 2.7이 두 연산자의 노름 통제. 2.3 보조정리 2.9(닐수열 비교)가 핵심 계산. 닐다양체의 단계(step)를 하나씩 낮춰 선형 위상까지 내려가는 "단계 줄이기"(Leng의 정리 2.8 사용)와 Weil 한계. 2.4 보조정리 2.11(Λ_Model의 양수성: 초포화)과 stashing으로 증명 마무리.
4. 절 3 (Z/NZ, 쪽 21–27). 정리 3.4가 핵심. 전달 가능이면 (g(x+P_1(y)), ..., g(x+P_t(y)))가 라이보만 닐다양체 G_Ψ/Γ_Ψ에서 같은 분포를 가짐. 리 대수와 Altman의 비플래그 정칙성 보조정리 방법을 씀. 정리 3.5는 주기적 닐수열 역정리(Manners).
- 새 아이디어의 위치: 정리 3.4(쪽 22–25)와 보조정리 2.9(쪽 11–17).

**방법이 막히는 곳.**
- 쪽 2 Remark 1.2와 쪽 18 Remark 2.12. P'(0)=0인 경우의 세 번 로그 한계는 Prendiville의 같은 차수 동차 결과가 초포화 단계(보조정리 2.11 세 번째 경우, 필요한 N이 exp(exp(δ^−O(1))) )에 들어가기 때문. 저자는 Leng–Sah–Sawhney의 준다항식 역정리로 "아마 개선될 것"이라 쓰고 세부는 독자에게 맡김.
- 쪽 18 보조정리 2.11. 초포화 단계가 항 수에 따라 나뉨. t=3, d'=1은 Kelley–Meka(지수가 exp(log(1/δ)^O(1))), t=4는 Green–Tao, t≥5는 Leng–Sah–Sawhney(이중 지수). 그래서 정리 1.1이 세 경우로 갈림.
- 쪽 21 정리 3.1과 쪽 26–27 증명 끝. 전달 오차가 log log N의 거듭제곱 지수인 것은 닐수열 복잡도가 exp(log(1/δ)^O(1))이고 균등분포에 N ≥ M'^(exp(D^O(1)))이 필요하기 때문(내 해석: 증명 마지막 줄 "N < M' exp(O(D^O(1)))"에서 읽음). 여기에 초포화가 로그를 하나 더 잃어 Z/NZ 최대밀도가 log log log N 꼴이 됨.
- 쪽 4 (절 1.1 끝). "완전 균등분포 닐수열로 줄이는" 현재 방식 대신 "단계 줄이기"로 비교를 증명하면 양적 개선이 가능할 수 있다고 저자가 지적.
- 쪽 12 Remark 2.10. 비교는 y와 z 각각의 나머지가 아니라 다항식 값(P_W(y), Q(z,y))의 나머지로 해야 함(저자가 "처음에 크게 혼란스러웠다"고 씀). P에 단순근이 있으면 W-속임수가 더 간단.
- 쪽 4–5. P'(0)=0이고 P''(0)≠0인 경우 W-속임수 후 비교가 안 맞아서 Prendiville의 결과(간격 (−Wz+1)y²인 등차수열)를 "양수성을 얻는 데" 다시 써야 함.
- 적용 범위의 경계(본문 구조에서 읽은 것): 정수에서는 고정된 P의 배수뿐, 일반 다항식 묶음은 아님. Z/NZ에서는 N이 소수이고 전달 가능이어야 함. 쪽 3의 두 번째 예(동차이지만 전달 불가)는 이 방법 밖.

### 2505.16822 — Shao, Wang, Quantitative bounds in a popular polynomial Szemerédi theorem (25쪽, 읽은 범위: 전체, v2 2025-11-11)

**주정리.**
- 정리 1.1 (쪽 2). P_1..P_m은 정수계수 다항식으로 서로 차수가 다르고 상수항이 0. A⊆{1..N}이 x, x+P_1(y), ..., x+P_m(y) (y≠0)를 포함하지 않으면 |A| ≪ N/(log N)^c. c는 다항식들에만 의존(값은 명시되지 않음). 쉬운 말: 필요한 밀도가 (log N)의 음의 거듭제곱 정도면 충분. 이전 Peluse의 (log log N)^(−c)에서 로그 하나를 줄임.
- 정리 1.2 (쪽 3), "인기 있는 차이". A⊆[N], |A|≥δN, ε는 (0,1/2)에서. N ≤ exp(exp(ε^(−O_P(1))))이거나, 어떤 양의 정수 y가 있어 #{x∈A : 모든 i에 x+P_i(y)∈A} ≥ (δ^(m+1) − ε)N. 쉬운 말: 모든 밀집 집합에는 "무작위 집합만큼 이상으로 많은 진행이 생기는 차이 y"가 있다.
- 정리 1.3 (쪽 3), 단순화된 역정리. 계수가 C 이하이고 차수가 서로 다른 P_i, d=최고 차수, M≍N^(1/d), 계수 연산자 Λ ≥ δ이면 M ≪ δ^(−O(1)) 이거나, q ≪ δ^(−O(1))와 q·Z를 따라 O(δ^(−O(1))M^(−deg P_i))-립시츠인 함수 φ_i가 있어 Σ_x f_i(x)φ_i(x) ≫ δ^O(1)N. 결론이 모든 i에 대해 성립(Peluse는 최저 차수 항 하나만).
- 일반형은 정리 2.4 (쪽 5): (C,q)-계수와 M ≤ (N/q^(d−1))^(1/d).
- 범위: 정수 {1..N}, 차수가 서로 다르고 상수항 0. 일반 다항식 묶음은 아님.

**증명의 뼈대.**
1. 절 2 (쪽 4–12), 역정리. 명제 2.5가 귀납 한 걸음: f_1..f_{j−1}이 립시츠 함수와 상관이면 f_j도 그렇다. Peluse의 정리 3.3(j=1)을 확장(쪽 6–10). 연산자를 반복해서 낮은 차수 항을 위상으로 바꾸고(보조정리 2.6), Weyl 부등식(보조정리 2.7)으로 위상이 주요 호(major arc)에 있음을 보이고, 립시츠 성질로 y 구간을 등차수열 조각으로 나눈 뒤 Cauchy–Schwarz와 van der Corput. 2.2는 Gowers의 분해 보조정리 2.8(Hahn–Banach)로 모든 f_j로 귀납을 확장(쪽 9–11, Remark에서 Manners의 stashing과 같은 기법이라 언급). 2.3은 일반 M을 부분구간으로 환원.
2. 절 3 (쪽 12–15), 국소 인자: 등차수열을 원자로 하는 분할(보조정리 3.5, 3.7로 존재와 사슬).

### 2608.01325 — Krachun, Square-Difference-Free Sets beyond the Three-Quarter Barrier (7쪽, 읽은 범위: 전체)

**주정리.** 정리 1 (쪽 2). D(N)은 {1..N}의 부분집합 중 서로 다른 두 원소의 차가 제곱수가 아닌(영이 아닌 제곱수 차이가 없는) 것의 최대 크기. 열 개의 쌍 (p_i, t_i) = (3,2), (7,3), (11,4), (19,5), (23,5), (31,7), (43,7), (59,9), (71,9), (103,11)에 대해 α_i = log t_i / log p_i 로 두면
liminf (log D(N) / log N) ≥ α* = (10 + Σ1/α_i) / (1 + 2Σ1/α_i) = 0.752796455874514…
쉬운 말: D(N)이 적어도 N^0.7528 정도로 큼. 이전 최고는 0.7334117…이고, Ruzsa 방법의 "자연스러운 장벽" 3/4(=0.75)를 처음 넘음. 정수 범위 {1..N}에서의 진술이고 상수 c는 숨은 하한.
- 내가 직접 계산해 확인: 열 개 쌍으로 α*=0.7527964558745, 표(쪽 5)의 열 개 사슬은 모두 정의 2를 만족, 작은 소수에서 가장 긴 사슬 길이 t(p)도 표와 일치(3→2, 7→3, 11→4, 19→5, 23→5, 31→7, 43→7, 59→9, 71→9).

**증명의 뼈대.**
1. 배경(쪽 1–2). Ruzsa: 제곱수 아닌 차이만 갖는 R⊆Z/mZ를 고르고 m진 전개의 자릿수를 번갈아 R로 제한하면 지수 (1 + log_m|R|)/2. m=65, |R|=7이면 0.733077. Beigel–Gasarch와 Lewko: m=205, |R|=12이면 0.7334117970. Ruzsa는 모든 소인수가 4로 나눈 나머지 1인 무제곱 m에서 |R|<√m을 증명하고 모든 m에서 |R|≤√m을 추측 → 3/4가 장벽.
2. 정의 2 (쪽 2). p≡3 (mod 4)인 소수 p에서 "파리(Paley) 사슬": (s_0..s_{t−1})로, a<b이면 s_b−s_a가 0이 아닌 제곱잉여. 파리 토너먼트의 전이적 부분 토너먼트에 해당.
3. 보조정리 3 (쪽 2–3, 국소 순위 블록). 모듈러스 p^(2e)에서 짝수 번째 자릿수를 S의 값으로 제한한 집합 C(p,S,e), 크기 (pt)^e, 순위 함수 h: 제곱 차이가 있으면 h가 엄격히 줄어듦. 핵심은 −1이 비잉여라서 방향이 정해지는 것.
4. 보조정리 4 (쪽 3–4, 블록에서 정수로). P가 완전제곱이고 C⊆Z/P가 순위 H인 블록이면 {1..(PH)^L}에 크기 |C|^L인 제곱 차이 없는 집합. 원소 X+P^L h_L(X)로 만듦.
5. 보조정리 5 (쪽 4, 중국인의 나머지 정리로 붙이기). 서로소인 제곱 모듈러스 블록들을 곱하면 크기와 모듈러스는 곱해지고 순위는 더해짐(H=1+Σ(H_i−1)). 이것이 새 아이디어(쪽 4). 소수 하나의 사슬로는 절대 0.7334를 못 넘지만(예: (3,2)는 log6/log18=0.6199) 여러 소수를 붙이면 넘음.
6. 지수 공식 (2.6). e_i=U/log t_i로 두고 U→∞이면 α*가 나옴 (쪽 5–6, 식 2.7–2.8).
7. 절 3 (쪽 6–7, 증명 없는 최적성 논의). 사슬 목록을 α(p)=log t(p)/log p 순으로 줄 세우고 (3.1)의 분수를 최대로 하는 개수 k를 고르면, 1000 이하 소수 중에서는 k=10이 최적.

**방법이 막히는 곳.**

**주정리.**
- 정리 1.1 (쪽 3). 충분히 큰 정수 N마다 실수 삼각다항식 P(θ)=a_0+Σ_{1≤n≤√N} a_n cos(2π n²θ)가 있어 P≥0(모든 θ), P(0)=1, 0 ≤ a_0 ≤ exp(−c√(log N · log log N)). c는 절대상수. 계수 a_n의 부호는 자유(양수만이 아님).
- 따름정리 1.2 (쪽 3, 증명은 부록 A 쪽 19). A⊆{1..N}이 영이 아닌 제곱수 차이를 갖지 않으면 |A| ≤ N exp(−c√(log N · log log N)) (N 충분히 큼). 이전 Green–Sawhney의 N exp(−c√(log N))보다 작음. 쉬운 말: 상한이 로그 기준 제곱근에 log log 인수만큼 더 줄어듦.
- 정리 1.3 (쪽 3, 증명은 부록 B 쪽 19–24). 같은 꼴의 P(P≥0, P(0)=1, 주파수는 n², n≤√N, 부호 자유)는 모두 a_0 ≥ exp(−C√(log N · log log N)). 쉬운 말: 이 부류의 다항식 안에서는 정리 1.1이 지수의 상수 c를 빼면 최적.
- 쪽 3: 계수가 모두 양수인 부류에서는 Ruzsa(Slijepčević 경유)에 의해 a_0 ≫ 1/log N이라 부호가 섞인 계수가 필수.
- 정의 쪽 2–3: van der Corput 증인은 주파수가 금지 차이 집합 F에 있는 코사인 다항식 P≥0, P(0)=1, a_0≤δ이고, 이것이 있으면 D(F,N) ≪ Nδ.

**주정리.**

- 정리 1.1 (쪽 2). A⊆F_3^n이 캡 세트이면 모든 정수 r≥1에 대해 크기 |B| = r|A|^(2r−2)인 캡 세트 B⊆F_3^(2nr)가 있다.
- 따름정리 1.2 (쪽 2). |A|=c^n이면 어떤 m>n에서 캡 세트 B⊆F_3^m이 |B|>c^m. 정리 1.1을 r>|A|²에서 쓰면 됨(|B|^(1/(2nr)) > |A|^(1/n) ⇔ r>|A|²).
- 정의 (쪽 2). F_q 위의 선형 방정식 L=c_1x_1+…+c_sx_s (s≥3, 계수 모두 0이 아님). "평행이동 불변"은 계수의 합이 0. "종수 1(genus one)"은 평행이동 불변이면서 공집합이 아닌 진부분집합 I의 계수합이 0이 아닌 것. L-자유 집합은 x_1=…=x_s인 자명한 해 외에 해가 없는 집합.

- 따름정리 1.4 (쪽 2). 종수 1에서 L-자유 집합 A가 |A|=c^n이면 어떤 m>n에서 L-자유 B⊆F_q^m이 |B|>c^m. 즉 직접 곱 하나만으로는 점근적 최적이 될 수 없음.
- 쉬운 말: 고정된 캡 세트 하나를 계속 곱하는 방법은 절대 최적이 아니다. 더 좋은 곱 이상의 구성이 항상 있다.

### 2408.02328 — Croot, Lev, Pach, Past and future of the cap set problem (11쪽, 읽은 범위: 전체)

**주정리.** 서베이이고 새 정리는 없음. 본문이 정리, 인용하는 결과는 다음과 같음.
- 쪽 1–3. Roth 문제와 밀도 증가. Roth O(N/log log N), Bourgain/Sanders N(log N)^(−1+o(1)), Bloom–Sisask가 로그 장벽을 넘음, Kelley–Meka N exp(−c(log N)^(1/11)), Bloom–Sisask가 1/9로 개선. Behrend 하한 N exp(−(2√(log 4)+o(1))√(log N)), Elkin, Elsholtz–Hunter–Proske–Sauermann가 상수 C=2√(log(24/7) log 2) < 2√(log 4)로 개선. k항 등차수열은 Erdős–Turán 추측(역수의 합이 발산하면 k항 등차수열), k≥5에서 Leng–Sah–Sawhney exp(−(log log N)^(c_k)), k=4 Green–Tao (log N)^(−c).
- 쪽 3–4 (절 2, 유한체). Meshulam |S|<c_p p^n/n. Bateman–Katz 3^n/n^(1+ε). Ellenberg–Gijswijt: 모든 소수 p≥3에 δ_p>0이 있어 |S|≪(p−δ_p)^n. Kelley–Meka의 유한체판 |S|≪2^(−κ_p n^(1/9)) p^n (대수적 방법보다 약하지만 다른 조합적, 푸리에적 방법보다는 훨씬 강함). 하한: Edel 2.217389, Tyrrell 2.218, FunSearch(Romera-Paredes 외) 2.2202, Naslund 2.2208, Elsholtz–Hunter–Proske–Sauermann의 (cp)^n (c>1/2, 모든 소수 p≥3).
- 쪽 4–8 (절 3, 대수적 방법). 조합 영점 정리(정리 1), CLP 보조정리 1(다중선형 다항식, |A|>2Σ_{i≤d/2}C(n,i)이고 모든 a≠b에서 f(a−b)=0이면 f(0)=0), Z_4^n에서 |S|<4^(cn), c≈0.926의 증명 스케치, Tao의 대칭 형식과 slice rank 정의(쪽 7)와 보조정리 2(대각 함수의 slice rank는 |A|), F_3^n에서 상한 3^(κn).
- 쪽 8 (절 4). 3-해바라기 없는 집합: Erdős–Szemerédi, Alon–Shpilka–Umans(캡 세트 상한에서 c=√(1+2.7552)=1.9378), Naslund–Sawin의 (2/2^(2/3))^(n(1+o(1)))≈1.8899^n. 행렬곱셈 알고리즘(군론적 접근)을 배제한 Blasiak 외.

**증명의 뼈대.** 절 3(쪽 4–8)이 CLP의 Z_4^n 논증을 쉬운 버전으로 따라가고(부분군 {0,2}^n, 다중선형 다항식의 차수 세기와 보조정리 1) 이어 Tao의 slice rank 논증으로 F_3^n 상한 3^(κn)을 보임(쪽 6–8). 새 아이디어를 찾는 문서가 아니라 방법의 설명서.

**방법이 막히는 곳.** 이 서베이 본문에는 "이 방법으로는 안 된다"는 한계 서술이 거의 없음. 확인 결과 본문에 "barrier", "limit" 같은 표현이 서베이 자체의 서술로는 없음(참고문헌의 Bloom–Sisask 제목에서만 barrier가 보임). 한계에 가장 가까운 서술은 두 곳:
- 쪽 4. Kelley–Meka의 F_p^n 한계가 대수적 방법의 지수적 절약보다 약함.
- 쪽 8–9 "Directions"의 질문들이 곧 "대수적 방법이 아직 못 가는 곳"을 가리킴.

**본문 전체에서 나온 열린 질문.** (쪽 8–9 절 5 Directions 전체. 다섯 개 모두 질문 형식.)
1. k≥4항 등차수열 없는 F_p^n의 최대 집합 크기를 대수적 방법으로 추정할 수 있는가 (쪽 8).
2. 차이가 {0,1}^n에 속하는 3항 등차수열만 피하는 제한된 차이 설정에서 대수적 방법을 쓸 수 있는가. 예: 그런 진행이 없는 S⊂F_3^n의 최대 크기 (쪽 8).

**1차 조사와 다른 점.**
