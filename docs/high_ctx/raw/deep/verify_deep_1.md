## 지정 쟁점

### 쟁점 1. 2503.09121 정리 1.11(ii)의 6p/11 구성은 Lev 추측의 반례인가

**원본의 추측 1.2 (`\begin{conjecture}[Lev] \label{conj:Lev}`, tex 200–208행, 2쪽).** p 소수, A, B ⊆ F_p, |B| ≤ |A|, R: B → A가 단사 함수일 때

- |A| + |B| ≤ p 이면 |A +_R B| ≥ |A| + |B| − 3
- |A| + |B| = p + 1 이면 |A +_R B| ≥ p − 3
- |A| + |B| ≥ p + 2 이면 |A +_R B| ≥ p − 2

(바로 앞 198행에서 "단사 함수 = A와 B의 부분집합 사이의 matching"이라고 동일시합니다.)

**정리 1.11(ii) (`\label{thm:counterexample_Lev}`, 300–308행).** 모든 소수 p에 대해 A ⊆ F_p, 대칭이고 최대 차수 1인 R ⊆ A×A가 있어 |A| = 6⌊p/11⌋ − 3, |A +_R A| = p − 3.

**판정: 셋째 가지의 반례입니다. 첫째 가지와는 무관합니다.**

- B = A로 두면 |B| ≤ |A|이고 |A| + |B| = 12⌊p/11⌋ − 6. p = 11q + r(0 ≤ r ≤ 10)로 쓰면 이 값이 p + 2 이상일 조건은 q ≥ r + 8이고, q ≥ 18(곧 p ≥ 199)이면 항상 성립합니다. 그보다 작은 p 중에도 157, 167, 179, 181, 191에서 성립합니다.
- 증명(620–640행)의 R은 A의 모든 원소를 정확히 한 번씩 덮는 대칭 matching입니다. 곧 R은 A에서 A로 가는 전단사(involution)이므로 "B → A 단사 함수"라는 가정을 엄격히 읽어도 만족합니다. p = 157, 199, 211, 397을 포함해 400 미만 소수 전부에서 구성을 직접 만들어 확인했습니다(`v_lev.py`): 크기 6⌊p/11⌋−3, R이 완전 대칭 matching, 빠진 합이 정확히 {−2, −1, 2}의 3개.
- 그러므로 p ≥ 199(및 위 몇 개)에서 가정은 셋째 가지를 만족하는데 결론이 p − 3 < p − 2입니다. 정리 1.11(iii)도 같은 구조(|A|+|B| > (1+δ)p, |B| ≤ εp, R이 B를 덮는 차수 1 관계)로 셋째 가지의 반례입니다.
- 저자 표현: 본문 문장은 "반례"라는 낱말을 쓰지 않고 "더 조심해야 한다"(210행), "(1+δ)p라는 더 강한 가정이 필요하다"(296, 328행)라고 씁니다. 그러나 LaTeX 라벨이 `thm:counterexample_Lev`, `coro:counterexample_Lev`이고, 296행은 "추측 1.2가 성립하려면 더 강한 가정이 필요함을 보인다"고 적어 셋째 가지가 진술대로는 거짓임을 사실상 인정합니다.
- 첫째 가지(|A|+|B| ≤ p)에 대해서는 이 구성이 아무 말도 하지 않습니다(616행: |A|+|B|−p가 음수면 이 기법은 이득이 없다). 1차 조사의 "반례가 아니다"는 첫째 가지에 한해서만 맞습니다.
- 주의: 위 추측 진술은 Ouyang이 옮긴 판입니다. Lev 원문(Lev00-ii)의 진술이 같은지는 이 원본으로 확인할 수 없습니다.

**노트(deep_D)에 대한 지적.**
1. 노트의 방향("셋째 줄과 모순되어 보인다")은 맞습니다. "내 해석, 전문가 확인 필요"는 "원본 진술 기준으로 반례(p ≥ 199에서 확인)"로 올려도 됩니다. 팩 권고 "'반례가 아님'이라고 단정하지 말고"는 "셋째 가지의 반례, 첫째 가지와는 무관"으로 바꾸는 편이 정확합니다.
2. "p+2를 훌쩍 넘는데"는 과장입니다. 초과분은 대략 p/11 − 8이고 작은 p(예 97, 101, 163)에서는 p+2에 못 미칩니다.
3. 덧붙일 사소한 사실: 정리는 "모든 소수 p에서 = p−3"이라 쓰지만 p = 23, 29, 31, 43에서는 빠진 합이 4–7개로 더 많습니다(≤ p−3은 성립, 서론 210행도 "≤ p−3"으로 씀). 홀수 경우 색인 집합의 "−(t−2)"는 −(t−1)의 오타로 읽어야 크기가 맞습니다.
