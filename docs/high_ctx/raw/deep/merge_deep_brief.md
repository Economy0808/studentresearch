# 병합 지침: 정독 노트에 검증 결과 반영

입력: 정독 노트 deep_*.md(Sonnet, 본문 전체 정독)와 검증 파일 verify_deep_*.md(Opus, LaTeX 원본 대조). 같은 폴더.
목표: 검증을 반영한 정독 최종본. **새로 조사하지 않습니다.** 두 파일의 정보만 씁니다.

규칙
1. 논문마다 노트의 형식(주정리 / 증명의 뼈대 / 방법이 막히는 곳 / 본문 전체에서 나온 열린 질문 / 1차 조사와 다른 점 / 팩 적합도 / 필요한 선행 논문)을 유지합니다. 노트 맨 위 머리말은 빼고 `### <arXiv>` 제목부터 시작합니다.
2. 검증자가 고친 내용은 본문을 고치고 문장 끝에 `〔원본 대조 수정〕`. 검증자가 확인만 한 쟁점의 결론은 해당 위치에 `〔원본 대조 확인〕`과 함께 한 줄로 적습니다.
3. 검증자와 정독자의 판단이 다르면 검증자(LaTeX 원본 기준)를 따르되, 검증자도 "확인 못 함"이라 한 것은 그대로 미확정으로 둡니다.
4. 각 논문 끝에 아래 형식의 요약 줄을 **정확히 이 모양으로** 붙입니다(나중에 표로 모읍니다):
   `> 요약 | <arXiv> | K<번호> | 적합도: 상/중/하(조건) | 권장 발췌: <절·쪽> | 뺄 부분: <절·쪽 또는 없음> | AI 관여: <없음 또는 무엇에> | 열린 질문 수: <n>`
5. 쉬운 말 유지. 원문 직접 인용은 15단어 이내, 논문당 한 번까지.

출력: 지정 파일에 Write. 마지막 응답은 파일 경로와 요약 줄들만.
