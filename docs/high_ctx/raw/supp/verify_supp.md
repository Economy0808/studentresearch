### 1. A1의 c 크기: 노트의 추정은 크기를 탑 수준으로 과소평가했습니다(수정 필요)
- 문서에는 c의 수치가 없습니다. c = a0/d이고, (9.13)에서 a0 = min{1/4, σ0/2, log(1/r)/(4 log M0)}입니다. r = 1−3ρ/4이고, 보조정리 8.1에서 ρ ≥ M0^−23입니다.
- 노트는 둘째 항(σ0/2)만 넣어 c ≲ 10^−7670을 얻었습니다. 부등식으로는 맞지만, 노트가 이것을 "extremely small의 구체적 크기"라고 쓴 것은 틀렸습니다.
- 셋째 항이 압도합니다. M0 = 8·∏_{3≤p<P} p이므로 log M0 ≈ P입니다. P는 (3.16)의 P_ref := max{3, (C*·r^n/c*)^16} 이상이어야 합니다(쪽 13 그림으로 r^n 확인, n = d/2, r = 24!/2). (3.19)의 P_mass = (2^(e0+1)·e0)^2, (3.22)의 C_exc^(16/17)보다도 커야 합니다. 이 하한들은 식으로 주어져 있습니다. 노트의 "문서에 수치가 없어"는 반만 맞습니다. 숫자로 계산해 두지는 않았지만 명시적인 공식은 있습니다.
- P_ref 하나만 써도 log10 P ≳ 16·n·log10(24!/2) ≈ 7.5×10^3832입니다(내 계산).
  - ρ ≤ 1만 써도 c ≤ log4/(4·d·log M0)이므로, 대략 c ≤ 10^(−7.5×10^3832)입니다.
  - 증명이 실제로 보장하는 값(ρ = M0^−23인 최악의 경우)으로 보면 log10 log10(1/c) ≳ 7.5×10^3832입니다. 곧 c는 세 겹 지수 크기입니다.
